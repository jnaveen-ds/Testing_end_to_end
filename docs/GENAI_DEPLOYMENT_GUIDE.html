Execute first

App 1 · Real-time Chat

Fargate-style API service, concurrent traffic, cache/token savings, TLS, revisions, and rollback.

Build

1
React Chat page
Prompt form, loading/error, response, token/latency, cache HIT/MISS.
2
Chat FastAPI
/health, /ready, POST /chat, typed schema and fake/Azure model seam.
3
Cache-aside
Scoped SHA-256 key, 15-minute TTL, successful results only, distributed lock.

Deploy and prove

  1. Build one immutable backend image in ACR.
  2. Deploy Chat FastAPI to Container Apps, min 0/max 3.
  3. Create paid Managed Redis only after estimate approval; TLS + Entra identity.
  4. Import OpenAPI into APIM and verify trusted certificate.
  5. Prove MISS→HIT and 20 duplicate misses→one model call.
  6. Break config, inspect logs, create revision, and rollback.
  7. Delete Redis immediately after evidence.
Why first? It establishes the image, Container Apps, APIM, identity, telemetry, HTTPS, and React deployment used by the next apps.

App 3 · Approval-gated Agent

Fast `202` contract, durable human wait, queue load leveling, retries, DLQ, TTLs, idempotency, and audit.

Build

1
React Agent page
Submit, plan, status timeline, Approve/Reject, completed/rejected/expired states.
2
Agent FastAPI
POST /runs, status, approval; returns run ID without holding request.
3
Durable workflow
Plan hash + external approval event racing ten-minute timer; approved work only enters queue.
4
Worker/state
Service Bus controlled concurrency + retries/DLQ; Cosmos status/audit + item TTL.

Deploy and prove

  1. Create Function runtime storage, Service Bus Standard queue, and eligible Cosmos free-tier account.
  2. Configure message TTL, dead-letter-on-expiry, max delivery 3, lock renewal.
  3. Deploy FastAPI facade, orchestrator, and worker identities.
  4. Approve one, reject one, let one expire.
  5. Reject duplicate and changed-plan approvals safely.
  6. Stop worker, watch queue grow, restart and drain.
  7. Force transient retry and poison-message DLQ/replay.
  8. Verify Cosmos record TTL.

CI/CD learning sequence

PR quality gate

backend-tests and frontend-build are protected check names. Fake providers prevent network/token charges.

Immutable package

Build one backend image and React artifact. Deploy sha-<commit>; use latest only for convenience.

OIDC deployment

GitHub requests short-lived identity with id-token: write. No Azure client secret. Health/readiness and three tiny smoke flows gate activation.
